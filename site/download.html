Downloads

Each release has packages for every platform. The desktop packages hold the shared library and its C header (ote.h), the viewer, the documentation and the license texts. Use them from CMake with find_package(OpenTAKEngine) or with pkg-config opentakengine. SHA256SUMS.txt in each release has the checksums.

  • Windows: the .zip
  • Debian and Ubuntu: apt install ./opentakengine_VERSION_amd64.deb (or arm64)
  • Fedora, RHEL, SUSE: dnf install ./opentakengine-VERSION-1.x86_64.rpm
  • FreeBSD: pkg add ./opentakengine-VERSION-freebsd-x86_64.pkg
  • OpenBSD, NetBSD, other Linux, macOS: unpack the .tar.gz anywhere
  • Android: the .aar library, or the viewer .apk to try it on a phone
  • iOS, iPadOS and macOS apps: the .xcframework.zip
  • .NET: the .nupkg, which carries the native libraries for Windows, Linux and macOS
