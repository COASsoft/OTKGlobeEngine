Download

Each release has packages for every platform. The desktop packages hold the shared library and its C header (otk.h), the viewer, the documentation and the license texts. Use them from CMake with find_package(OTKGlobeEngine) or with pkg-config otkglobeengine. SHA256SUMS.txt in each release has the checksums.

  • Windows: the .zip
  • Debian and Ubuntu: apt install ./otkglobeengine_VERSION_amd64.deb (or arm64)
  • Raspberry Pi 4 and 5 (64-bit Raspberry Pi OS): sudo apt install ./otkglobeengine-VERSION-raspberrypi-arm64.deb, built for their OpenGL ES 3.1 GPUs
  • Fedora, RHEL, SUSE: dnf install ./otkglobeengine-VERSION-1.x86_64.rpm
  • FreeBSD: pkg add ./otkglobeengine-VERSION-freebsd-x86_64.pkg
  • OpenBSD, NetBSD, other Linux, macOS: unpack the .tar.gz anywhere
  • Android: the .aar library, or the viewer .apk to try it on a phone
  • iOS, iPadOS and macOS apps: the .xcframework.zip
  • .NET: the .nupkg, which carries the native libraries for Windows, Linux and macOS

What changed in each version is on the changelog.
