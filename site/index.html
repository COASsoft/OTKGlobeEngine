OpenTAKEngine is a map engine. It draws a 3D globe with satellite imagery, terrain, map features, military symbols and 3D models, and it keeps working when the network goes away.

It's written in C++ and runs on Windows, Linux, macOS, iOS, Android, FreeBSD, OpenBSD and NetBSD. Programs use it through a plain C API, so it can be called from C, C++, C#, Java, Kotlin or Swift. The download page has packages for all of those.

It behaves like the map engine inside the TAK apps (ATAK, WinTAK), but it was written from scratch and contains no TAK code. It is not affiliated with, endorsed by, or associated with tak.gov, the TAK Product Center, or the makers of any TAK product.

What it does:

  • Globe and flat map, imagery from tile servers, WMS, WMTS, MBTiles, GeoPackage and GDAL; terrain from DTED, SRTM, quantized-mesh and Terrarium.
  • KML/KMZ, GeoJSON, GPX, Shapefile, CSV, CoT and TAK data packages, with labels and picking.
  • MIL-STD-2525 symbols, MGRS/UTM/GARS grids and coordinates, magnetic declination, range rings, bullseyes, line of sight, viewshed and contours.
  • Sun and moon, twilight times and night illumination for NVG planning; drone video footprints from MISB KLV metadata.
  • glTF models and 3D Tiles: photogrammetry, Google Photorealistic 3D Tiles, Cesium ion, Draco and KTX2 compression.
  • Offline and airgapped networks: a cache that serves old tiles when servers are unreachable, region downloads, MBTiles/GeoPackage transfer.
  • VR and AR headsets through OpenXR, and side-by-side stereo.

The license is the Apache License 2.0: use it for anything, change it, sell it, in open or closed products, without sharing your changes. Copies you hand on keep the license text. The libraries it bundles keep their own (mostly MIT-style) licenses, listed in THIRD_PARTY.md.

To build it from source you need CMake and a C++20 compiler:

git clone https://github.com/grangedevgroup-code/OpenTAKEngine
cd OpenTAKEngine
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build
build/apps/viewer/ote_viewer

Bug reports and patches go to the issue tracker. Security problems go to the address in SECURITY.md instead.
